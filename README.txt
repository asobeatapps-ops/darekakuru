ASOBEAT - 23:59、誰かが来る。 Ver.1.0
==========================================

起動方法
1. index.html をブラウザで開きます。
2. 「スタート」を押し、部屋の物をタップしてください。
3. 15種類のエンディングを探して、謎を解き明かしてください。

GitHub Pages で公開する方法
1. GitHub に新しい公開リポジトリを作成します。
2. index.html をリポジトリの一番上の階層にアップロードします。
3. Settings → Pages で main ブランチの /(root) を公開します。
4. 公開URLで動作を確認してください。

必要な外部画像・外部ライブラリ・APIキーはありません。
プレイ履歴はブラウザの localStorage に保存されます。
ブラウザのデータを削除した場合、図鑑の進捗も消えます。

推奨環境: iPhone Safari / Android Chrome / PC Chrome・Edge の現行版
スマートフォン・PCで操作できます。
